# Agent Skills

My plugin marketplace for [Claude Code](https://claude.com/product/claude-code) (and other compatible agents).

## Installation

### Claude Code

#### Marketplace

```sh
/plugin marketplace add yasanglass/agent-skills
```

#### Local

Add the plugin contents to your `.claude` folder.

## Plugins

### [kotlin-skills](plugins/kotlin-skills)

```sh
/plugin install kotlin-skills@yasanglass
```
